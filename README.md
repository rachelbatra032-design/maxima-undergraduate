# maxima-undergraduate

wxMaxima worksheets from the Differential Equations paper at
St Stephen's College, University of Delhi (2022).

`code/` is plain-text Maxima. Open a file there to read the program.
`worksheets/` is the original wxMaxima file. `pdfs/` is the printed output —
click a PDF on GitHub to preview it (diffs will say “binary file not shown”;
that is normal).
